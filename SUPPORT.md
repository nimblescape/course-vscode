# Support

## Questions and problems

Ask a question or report a problem as an
[issue on GitHub](https://github.com/nimblescape/course-vscode/issues).
Search the existing issues first. When an issue describes your problem
already, add your information to that issue.

A report helps most when it contains:

- the version of the extension or of the command `course`, and the version
  of VS Code ("Help", "About") or of Node.js;
- your operating system;
- the shortest README of a course that shows the problem, in a code block,
  and the settings of the course in `.course/course.yml`;
- what you expected, and what you see instead, for example the warning or
  the output of `course check`.

The
[specification of the format](https://github.com/nimblescape/course-vscode/blob/main/docs/format.md)
describes the files of a course and the checks.

## Security problems

Do not report a security problem in a public issue. Write an e-mail to
scalarion@nimblescape.com instead.
