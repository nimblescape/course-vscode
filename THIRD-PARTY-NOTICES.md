# Third-party notices

The script of the course extension nimblescape Course, `dist/extension.js`,
contains the Markdown parser markdown-it with the packages that it uses, and
the YAML parser yaml. The course module reads the files of a course with
markdown-it, as the Markdown preview of VS Code does, and the settings of a
course in `.course/course.yml` with yaml. The command `course` of the npm
package `@nimblescape/course`, `cli/dist/course.js`, and its library
`cli/dist/index.js` contain the same packages, and the npm package holds this
file. This file names each of these packages, its license and the place of
its source code. The code of the course module itself is under the
[MIT License](https://github.com/nimblescape/course-vscode/blob/main/LICENSE).
